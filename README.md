# Lamp Store

## English

Lamp Store is a web catalog for handmade lamps and 3D models.
The project allows users to view products and send order requests without online payment.

## Русский

Lamp Store - это веб-каталог авторских ламп и 3D-моделей.
Проект позволяет пользователям просматривать изделия и отправлять заявки на заказ без онлайн-оплаты.
